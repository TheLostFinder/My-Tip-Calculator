## 3. Stack & Design Choices

### Stack
- HTML
- CSS
- JavaScript

### Why
I used simple HTML/CSS/JS because the project is small and does not need a framework. 

### Design Choices
- Real-time calculation while typing
- Simple centered layout
- Inline error messages
- Responsive design using Flexbox

---

## 4. Responsiveness & Accessibility

### On Phone (360px)
- Layout stays readable
- Inputs stack properly
- Buttons remain easy to tap

### On Laptop (1440px)
- Content stays centered
- Layout does not stretch too much

### Accessibility
- Proper labels for inputs
- Keyboard navigation works
- Good text contrast
